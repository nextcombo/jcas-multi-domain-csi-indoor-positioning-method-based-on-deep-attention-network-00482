# [JCAS] Multi-Domain CSI Indoor Positioning Method Based on Deep Attention Network in MIMO JCAS System with Python Code

Indoor positioning is crucial for the future 6G systems that integrate communication and perception. Accurate positioning is essential for applications such as augmented reality and autonomous robots. In this context, we propose a localization method based on multi-domain channel state information (CSI) using deep attention networks (DAN) in large-scale multi-input multi-output (maMIMO) systems. We introduce features extraction from multiple domains of CSI information, including time, frequency, and Doppler, and design single-domain and multi-domain feature sets. We leverage an attention mechanism to implement the proposed DAN method to integrate and effectively process multi-domain CSI data. We evaluate the model performance using publicly available maMIMO datasets and compare it with baseline convolutional neural network (CNN) models. The results show that the proposed DAN method outperforms single-domain, multi-domain CNN models, as well as existing multi-domain CNN benchmarks in terms of positioning performance. These findings highlight the benefits of using multi-domain features (especially Doppler domain features) and attention mechanisms for reliable indoor positioning.
Introduction Positioning and Perception are becoming key drivers for the development of future sixth-generation (6G) indoor joint communication and perception (JCAS) systems. The demand for next-generation wireless indoor applications, such as connected robots, digital twins, and augmented reality, goes beyond the unprecedented bandwidth and throughput demands at higher frequencies to require high-precision positioning information. Global positioning systems often struggle in indoor environments to accurately locate users. A growing trend is to reduce system costs by leveraging existing wireless infrastructure as a reference point for indoor positioning systems. Wireless measurements, such as channel state information (CSI), received signal strength indicator (RSSI), and arrival angle (AoA), are affected by human movement within the communication environment. These measurement values obtained from 6G massive multiinput multioutput (mmIMO) wireless systems can also be used for human positioning and perception without adding any additional overhead to the communication environment. Recent research emphasizes the application of neural networks (NN) in indoor positioning based on CSI, with convolutional neural networks (CNN) being the most common architecture. In [4], CNNs are used to construct images from estimated AoA values for positioning. In [5], authors deployed CNN architectures on features extracted from CSI information, such as polar coordinates, frequency domain raw features, and cartesian form of time domain information. In [6], ResNet blocks were enhanced by CNNs, while in [7] spatial-temporal CSI features were utilized for positioning. Various NN architectures, such as feedforward NNs, Transformers, and federated learning, have been explored for indoor positioning using fifth-generation (5G) and cellular CSI. Fusion architectures based on NNs and integrated NNs have also been investigated. In all these methods, carefully designed CSI features are crucial due to small-scale fading and hardware damage. All these works extract various features from raw CSI data, such as amplitude, phase, polar coordinates, and autocorrelation across frequency, time, and Doppler domains. In this work, we explore CSI feature extraction from multiple domains including frequency, time, and Doppler. We design a Deep Attention Network (DAN) architecture by combining deep attention modules with CNNs for indoor positioning based on CSI. We implement our proposed architecture using the publicly available mmIMO CSI dataset and compare its performance with CNN baselines. In this paper, CNN baselines include both with and without transfer learning (TL) models for comparison. We analyze the combination of multi-domain feature selections extracted from CSI data using the designed deep attention architecture. The rest of the paper is organized as follows: Section 2 describes the setup of the indoor mmIMO CSI dataset. Section 3 introduces the construction of multi-domain features. Section 4 describes the CNN baselines and proposed DAN architecture. Section 5 analyzes the multi-domain CNN and proposed DAN positioning performance under different multi-domain CSI feature sets. Section 6 summarizes conclusions and future work.

Conclusion In this paper, we propose a multi-domain DAN framework for indoor positioning of UEs based on CSI in maMIMO systems. We first construct a multi-domain feature set by extracting CSI information from the Doppler domain and both time and frequency domains. We analyze the position prediction performance using single-domain and multi-domain feature sets on a CNN baseline architecture. In the single-domain feature set, we observe that features constructed from the Doppler domain lead to better prediction accuracy. When training a CNN with the multi-domain feature set (excluding time and frequency domain features but including Doppler domain features), we also see the same phenomenon. Applying this knowledge to an attention mechanism, we compare the proposed DAN-based position estimation performance with the multi-domain CNN baseline and previous CNN benchmark results. Our results demonstrate that the proposed multi-domain DAN method outperforms the CNN baseline and the multi-domain CNN in terms of position estimation performance. Some promising results are demonstrated through the attention mechanism, and our analysis can be extended to DAN frameworks with different attention mechanisms, using large amounts of CSI samples under different antenna configurations, as well as scalability, computational complexity, etc.
